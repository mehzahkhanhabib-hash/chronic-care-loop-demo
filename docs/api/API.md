# Chronic Care Loop · REST API

Base URL `http://localhost:4000/api`. JSON in, JSON out. Send `x-user: <user_id>` (e.g. `U-0150`) so writes are attributed; the demo has no real authentication.
Every response below is a real, trimmed response from the seeded database (generated by `node scripts/gen_api_docs.js`).
